# 🖼️ Responsive Image Gallery

A responsive image gallery built using HTML, CSS, and JavaScript. This project allows users to explore images through category filters and an interactive lightbox.

## 🌐 Live Demo

[View the Live Website](https://miruthikashree.github.io/CodeAlpha_ImageGallery/)

## ✨ Features

- Responsive image grid for different screen sizes
- Category-based image filtering
- Interactive lightbox to view images
- Next and previous image navigation
- Smooth hover transitions and animations
- Simple and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, responsive layout, and transitions
- **JavaScript** — Filtering and image navigation

## 📁 Project Structure

```text
CodeAlpha_ImageGallery/
├── index.html
├── style.css
├── script.js
└── images/
    ├── nature1.jpg
    ├── nature2.jpg
    ├── animal1.jpg
    ├── animal2.jpg
    ├── art1.jpg
    └── art2.jpg
```

*Note: The filenames above are examples. Your images folder may contain different image filenames.*

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension, or open it directly in a browser.
